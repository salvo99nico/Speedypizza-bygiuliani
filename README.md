# Speedy Pizza by Giuliani – sito web
Sito statico (HTML/CSS/JS, nessuna dipendenza). Funziona direttamente su **GitHub Pages**.

## Pubblicazione
1. Crea un repository su GitHub e carica tutto il contenuto di questa cartella.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.

## Da completare
- `index.html` e `privacy.html`/`cookie.html`: inserire la **Partita IVA** e i testi legali.
- Link **Deliveroo** e **Just Eat**: sostituire `https://deliveroo.it` e `https://www.justeat.it` con le pagine del locale.
- Verificare la nota "* Prodotti decongelati" con il menù in negozio.
- Foto: sostituire `img/locale.jpg` (hero), `img/antonio-giuliani.jpg` e aggiungere foto delle pizze.

## Modificare il menù
Tutto il menù è in `js/menu-data.js`: una riga per pizza (`Nome|Ingredienti|Allergeni|Prezzo`).
